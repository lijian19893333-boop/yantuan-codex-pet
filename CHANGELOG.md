# Changelog

## 1.0.0 — 2026-10-23

- Initial open-source package for Yantuan / 焰团.
- Preserves the installed sprite-version-2 artwork, including the 2026-09-27 idle-tail refinement.
- Adds bilingual installation and provenance documentation, an offline preview, protected installer and image validation tools.
- Includes no original reference photo, account data, private generation records or desktop application code.
- File and installer checks cover this package. Host compatibility outside the maintainer's existing macOS setup is not established.
